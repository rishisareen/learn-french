# Milestone Gates

Check a gate only when the checkpoint is actually passed, not when the calendar says so.

## Week 1 setup
- [ ] Deconstruction afternoon done (12 sentences in French)
- [ ] Pimsleur MP3s downloaded + audiobook player set up
- [ ] Anki installed with French 5,000-frequency deck
- [ ] AI tutor set up: one tool chosen (ChatGPT or Gemini), standing prompt / custom Gem configured (level, correction format, error log)
- [ ] Grammar spine chosen (Assimil or Français interactif) and started
- [ ] Human tutor booked — weekly slot, 10–20 session package pre-paid (stakes)
- [ ] Target test month written down where family can see it

## Month 3 — A1 + adherence gate
- [ ] Grammar spine A1 material finished
- [ ] Pimsleur Level 1 passed, Level 2 underway
- [ ] Can introduce self, handle present tense, ~1,000 words mature in Anki
- [ ] **Adherence gate:** AI voice sessions ≥5 days/week held for the last month; Anki streak alive
  - Held → continue DIY into A2
  - Slipped 2–3 weeks → buy structure (AF intensive or more human tutor hours) for the next phase

## Month 7 — A2
- [ ] DELF A2 past paper: comfortable score
- [ ] Past + future tenses in free conversation
- [ ] Daily paragraph + AI correction habit running (since Month 2)
- [ ] Listening load shifted to real French audio — *InnerFrench*/RFI (AI conversation doesn't count as listening practice)

## Month 12 — B1
- [ ] 30-minute conversation with human tutor without switching to English
- [ ] *InnerFrench* comfortable at normal speed
- [ ] Mock TCF ≈ NCLC 5–6
- [ ] **Switched weekly human tutor to a TCF/TEF-experienced one**
- [ ] **Started watching TCF Canada slot openings at AF Delhi**

## Month 15 — B2 threshold
- [ ] Full timed mock (human-scored) ≈ NCLC 7 in at least 3 of 4 skills
- [ ] Exam-prep phase started (task templates; unlimited AI task practice + 4+ human-scored timed mocks)
- [ ] Test slot booked

## Month 16–18 — Test
- [ ] TCF Canada taken
- [ ] Result: NCLC ___ / ___ / ___ / ___ (listening / reading / writing / speaking)
- [ ] If any skill < 7: retake booked (buffer to Month 20)

## Parallel immigration track (year 1)
- [ ] FSW 67-point eligibility confirmed (professional advice)
- [ ] ECA obtained
- [ ] IELTS/CELPIP (English) done
