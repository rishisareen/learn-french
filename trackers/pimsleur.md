# Pimsleur French Tracker

One 30-min lesson per commute day. A box gets checked only when **passed** (~80% of responses produced on time) — replay the next day otherwise. Note repeats in brackets, e.g. `L1-07 [x2]`.

Plan: Levels 1–3 are the core (Months 1–5). Continue into 4–5 only while it still feels harder than *InnerFrench*; otherwise switch the commute to podcasts.
